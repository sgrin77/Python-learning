# Python-learning

A browser-based Python learning app for Lucas. See the feature branch for the
full implementation.

## Soccer Log

`soccer/` holds **Keeper & Striker Log**, an installable phone app for
tracking games, mistakes, and drills for a goalkeeper and striker. See
[soccer/README.md](soccer/README.md) for setup and iPhone install steps.

## MarketWatch Trade Alerts

`mw-trade-alerts/` gets you alerted when a MarketWatch stock game player
trades. See [mw-trade-alerts/README.md](mw-trade-alerts/README.md) for setup.
